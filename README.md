# Covalent

***Covalent*** (Collective Variables Learned by a computer) is a supervised machine learning-based collective variable discovery pipeline that combines a filter-wrapper-substitution feature funnel with an improved, Riemannian-optimized variant of harmonic linear discriminant analysis (GDHLDA) and a post hoc subspace rotation to concentrate pairwise transition information.

***Covalent*** casts the task as a supervised classification problem and consists of six main steps designed to maximize both the distinguishability and interpretability of CVs. Please refer to the following articles for details:

  * J. Chem. Theory Comput. 2025, 21 (23), 12356-12370. (https://doi.org/10.1021/acs.jctc.5c01402)
  * Biophys. J. 123 (17), 2934-2955. (https://doi.org/10.1016/j.bpj.2024.06.024)
